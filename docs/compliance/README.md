# Compliance evidence

This directory holds version-controlled templates and non-secret release evidence for QuantClarity's privacy, source, and security gates. It is not legal advice and does not replace authorized legal-owner decisions.

Do not commit identity documents, data-subject correspondence, signed agreements containing confidential terms, Cloudflare account identifiers, credentials, personal contact records, or processor exports. Store those in the approved private legal/operations system and commit only a dated approval record and integrity hash when appropriate.

- [`privacy-notice.md`](privacy-notice.md) is the public notice draft. Release-blocking placeholders must be resolved by the controller.
- [`gdpr-accountability.md`](gdpr-accountability.md) is the evidence index for `GATE-gdpr-accountability`.
- [`processing-record.md`](processing-record.md) is the public-safe record-of-processing template.
